# 五反田さんぽ
バンタンの1年次前期審査会課題-五反田さんぽ

## サイト制作 要件整理
### 課題
トラベル系のサイトはフード系や店舗の紹介がメインなので、五反田の風土などが分かりづらく。
とりあえず、お店に行ってみようみたいな散歩になりがちで、もっとぶらぶら散歩に行く情報が載っているサイトを作りたい。

### ゴール
本サイトをご覧になることで、交通や建造物などの歴史を知ってもらい。
知らないと通り過ぎてしまうようなところ目を向けてもらって五反田のさんぽを楽しんでもらう。

## ターゲットユーザー/ペルソナ
1. 五反田で空き時間ができてしまった社会人
2. リタイア後の老夫婦
3. 育児が終了した夫婦

## 競合他社分析
1. ブログ記事形式で、いくつかのスポットがきれいな写真と説明が並んでいる。[skyticket](https://skyticket.jp/guide/19091/)
2. ブログ記事形式で、初めに五反田地図があって道のイメージがしやすい。[東急](https://www.tokyu.co.jp/area/gotanda/article/arti-01JV149W8MBZ7E9N5ZHD6ABEK6/)
	- ブログ記事の形式が多く、文字量が多いかイメージ写真が多様してあるサイトがおおい。
	- 位置関係や散歩ルートが分かりやすいと差別化できる。
	- ブログ記事の形式などで縦長に並んでるだけのことかが多い。ページ階層分けして整理したい。


## サイトコンセプト
- ブログ記事形式が多いので五反田の点在しているスポットの全体像がつかみにくいので、位置情報を分かりやすく明記したい。
- スポットごとにページ階層で整理して、全体像と詳細を分けて整理したい。
- 写真がずらずら多様するのではなく、hoverかカルーセル・スライダーを使ってコンパクトにまとめたい。


## デザインコンセプト
メインカラーを緑にしたいですが、暖色を混ぜて温かく、まったりした印象を与えるデザイン
